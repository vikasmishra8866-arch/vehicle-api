# Elite Vehicle Desk — Vehicle Lookup API

Private office API. No cache, no storage — direct source call.

## Endpoint

GET /api/vehicle?number=GJ05MS9717

Headers: x-api-key: <OUR_API_KEY>

## Deploy

1. GitHub pe repo push karo
2. Vercel pe import karo
3. Environment variables:
   - SOURCE_API_KEY
   - OUR_API_KEY
4. Deploy
